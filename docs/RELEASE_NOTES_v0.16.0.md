# PocketLab v0.16.0 Public Beta

PocketLab turns an M5StickS3 into an offline, privacy-focused learning and diagnostic companion.

## Highlights

- Local WebUI at `http://pocketlab`
- Battery and power-management dashboard
- Passive Wi-Fi survey and channel chart
- No-logging Wi-Fi signal explorer with smoothed room measurements
- On-demand BLE inventory
- BLE HID keyboard pairing and key tester
- Internal-flash file vault
- All-ages Cyber Academy checklist
- Expandable networking glossary
- Nova splash screen and responsive artwork

## Install

Flash the attached factory image to an **M5StickS3 only** at offset `0x0000`. Installation erases existing firmware, PocketLab files, baselines, and settings.

## Public-beta notice

Additional reliability, compatibility, and usability updates are expected. Please report reproducible issues without including passwords, private network details, or other sensitive information.

Use PocketLab only with equipment and networks you own or have permission to examine.
