## Short description

Offline, privacy-focused Wi-Fi and Bluetooth learning toolkit with a local WebUI and Cyber Academy.

## Full description

PocketLab is an offline, privacy-focused Wi-Fi and Bluetooth learning toolkit for the M5StickS3. It includes a local WebUI, Cyber Academy checklist, Wi-Fi signal and channel analyzer, BLE inventory, Bluetooth keyboard tester, file vault, battery monitoring, and expandable networking glossary.

PocketLab does not crack passwords, disconnect devices, attack networks, upload telemetry, or require internet access. Cyber Academy measurements and checklist progress remain temporary unless the user explicitly saves a survey from the main tools page.

Public beta: additional reliability, compatibility, and usability updates are planned. Use only with equipment and networks you own or have permission to examine.

Important: installing this factory firmware erases existing applications, PocketLab files, baselines, and settings on the device.
