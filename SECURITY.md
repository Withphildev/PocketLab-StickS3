# Security policy

## Supported version

PocketLab is currently a public beta. Security fixes are applied to the latest release only.

## Reporting a vulnerability

Please do not publish a working exploit or sensitive device information in a public issue. Open a GitHub security advisory for the repository owner, or contact the maintainer privately through the contact method listed on their GitHub profile.

Include the PocketLab version, M5StickS3 hardware revision if known, reproduction steps, and the security impact. Do not include real Wi-Fi passwords, private keys, or personal data.

## Scope

PocketLab creates a local Wi-Fi access point and serves an HTTP WebUI. It is designed for short-range, offline learning and diagnostics—not for exposure to the public internet or use as a security boundary.
