# Nova Core WebUI Sprites v1

Generated from the two user-supplied Nova references with the built-in image generation workflow.

## States

- `nova-idle`: relaxed, friendly default state
- `nova-scanning`: focused, holding a handheld wireless scanner
- `nova-success`: happy thumbs-up confirmation
- `nova-warning`: calm attention/pause gesture

`masters/` contains the 1024 x 1536 transparent PNG masters. `web/` contains 256 x 384 transparent PNG copies prepared for the PocketLab WebUI.

## Shared prompt direction

Full-body chibi anime UI sprite; preserve Nova's deep indigo hair, brown eyes, black hooded techwear, cargo pants, combat boots, face, and proportions; crisp dark outlines, clean cel shading, cyan/violet rim highlights; transparent background; no text, UI panel, scenery, shadow, or watermark.
