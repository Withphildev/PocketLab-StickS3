# Changelog

All notable PocketLab changes are documented here.

## [0.16.0] - 2026-10-07

First public-beta candidate.

### Added

- Offline PocketLab WebUI served by the M5StickS3.
- QR-assisted connection to the private PocketLab access point.
- Device, battery, power-profile, display, and portal controls.
- Passive Wi-Fi survey with channel visualization and optional CSV/JSON reports.
- On-demand BLE inventory with optional CSV/JSON reports.
- BLE HID keyboard pairing and on-device key tester.
- Internal-flash file vault.
- Nova splash screen, assistant states, and responsive section artwork.
- All-ages Cyber Academy with a session-only home-network checklist.
- Expandable plain-language networking glossary.
- No-logging Wi-Fi signal explorer with selected-network details.
- Rolling five-reading median plus latest, strongest, and weakest signal values.
- Nine-second walk-test interval, three-minute automatic stop, and background-tab pause.

### Safety and privacy

- Cyber Academy does not crack passwords, disconnect devices, or attack networks.
- Practice-password text stays in the browser and is not transmitted to PocketLab.
- Academy checklist and signal history remain in browser memory and clear on refresh.
- WPS guidance explicitly requires checking the owner's router settings rather than claiming scan-based detection.
